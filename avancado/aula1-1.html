💻 Aula 1.1 — Manutenção e Otimização do Windows

O que vamos aprender:

  • ✅ Limpar arquivos temporários
  • ✅ Desativar programas que iniciam sozinhos
  • ✅ Verificar e corrigir erros do sistema
  • ✅ Deixar o computador mais rápido!

📝 Passo a Passo:

1. Limpeza de Arquivos:
Pressione Windows + R → digite cleanmgr → Enter → Selecione C: → Marque tudo → OK

2. Gerenciar Inicialização:
Pressione Ctrl + Shift + Esc → Aba "Inicializar" → Clique com botão direito → Desativar programas que não usa

3. Verificação de Erros:
Abra o Prompt de Comando como Administrador → digite: sfc /scannow → Enter → Espere terminar!

✅ Concluiu? Marque como concluído no painel e avance para a próxima aula!
